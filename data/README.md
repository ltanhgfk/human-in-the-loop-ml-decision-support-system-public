# data/

Real-world MMS payloads and user-submitted data (originally at
`RSSAPP/mms/`, 17 files, ~996 KB) are excluded from the public
repository for privacy reasons. They were real messages/media received
by the live system from real farmers, and no consent-for-public-
redistribution was obtained for that material at collection time.

They remain present, untouched, in the private local original copy
(`ORIGINAL_PRESERVED/` and the `pre-phase2` git branch) and are excluded
from the `phase2-clean` branch via `.gitignore` (`RSSAPP/mms/`).

See `docs/DATA_PRIVACY.md` for the full privacy audit.
