# Data Privacy and Public Repository Rules

This repository is a public-facing reconstruction of a historical research/software project.

Do not commit:

- phone numbers belonging to real users
- names, addresses, email addresses, IDs, or account credentials
- real SMS/MMS payloads
- database dumps or backups
- trained models or datasets derived from private/historical records
- local server/modem configuration containing credentials or network details

Use the example configuration files under `config/` and fictional data only.

The original repository history is deliberately not preserved in the public repository because the historical snapshot contained private/runtime material.
