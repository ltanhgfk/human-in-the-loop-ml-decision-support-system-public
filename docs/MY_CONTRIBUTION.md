# Research Contribution Summary

This project should be described as an **information-system implementation containing a human-in-the-loop machine-learning decision-support workflow**.

## Contributions evidenced by the preserved project

- Designed and implemented a Vietnamese text-processing pipeline for agricultural SMS questions.
- Implemented domain-specific keyword/feature construction and sparse vector generation.
- Integrated a linear-kernel SVM classifier into the application workflow.
- Implemented multi-class routing of agricultural questions by domain.
- Preserved separate machine-generated and human-validated classification states.
- Integrated classification with expert routing and response handling.
- Implemented a retraining workflow using newly labelled messages.
- Integrated term-frequency cosine similarity for retrieval of previously answered questions.
- Connected the ML workflow to a Java web/application system and MySQL database.

## How to describe the work

A concise research-oriented description is:

> **Designed and implemented a human-in-the-loop machine-learning decision-support system for Vietnamese agricultural question classification, expert routing, and iterative model retraining through SMS/MMS.**

## Claims to avoid

Do not describe the original project as:

- an LLM system
- a transformer-based NLP system
- a RAG system
- an embedding-based semantic search system
- a modern multimodal ML system
- a fully autonomous agricultural expert system

Those capabilities belong to later/future work and are not established by the preserved implementation.
